# سكريبت الأصوات — Google AI Studio

## كيفاش
1. دخل لـ **aistudio.google.com** ← **Generate speech** (Gemini TTS)، وختار **Single-speaker audio**.
2. لكل شخصية: ختار **الصوت** المكتوب تحت، وحط **Style instructions** ديالها مرة وحدة.
3. لصق الجملة ← **Run** ← نزل الملف، وسميه بالاسم اللي حداها (مثلا `intro_1.wav`).
4. حط الملفات كاملين فـ `atlas-knights/assets/voice/` وقولي، أنا غادي نحولهم لـ mp3 خفاف ونربطهم.

> ما خاصكش تقادهم كاملين دقة وحدة: كل ملف ناقص، اللعبة كتقراه بالصوت ديال المتصفح (ولا بالبيب ديال الحروف).
> الأهم: **الراوي (tut_ و intro_)**.
